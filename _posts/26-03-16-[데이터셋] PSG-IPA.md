# PSG-IPA: A PolySomnoGraphic Inter-scorer Performance Assessment database

> https://physionet.org/content/psg-ipa/1.0.0/

데이터셋 크기는 <strong>작지만, annotation 구조가 매우 강력한 multi-rater PSG dataset</strong>

---
## ℹ️ Data Info

| 항목            | 내용                                                                                    |
| ------------- | ------------------------------------------------------------------------------------- |
| 샘플 수          | 20 PSG recordings                                                                     |
| 세부 구성         | sleep staging 5, EEG arousal 5, respiration 5, leg movement 5                         |
| 기록 길이         | median TIB 7.3 h [7.0, 8.0]                                                           |
| 주요 채널         | EEG, EOG, chin EMG, leg EMG, ECG, nasal pressure, thoracic/abdominal effort, SpO2     |
| 샘플링 주파수       | EEG/EOG/ECG/flow 256 Hz, chin EMG 256 Hz, leg EMG 128–256 Hz, effort 32 Hz, SpO2 4 Hz |
| 라벨            | sleep stages, EEG arousals, respiratory events, leg movements                         |
| annotation 구조 | 12 expert scorers, manual / semi-automatic / automatic annotation 제공                  |

---
## 🔔 수집 목적

inter-scorer variability(판독자간 일치도)를 측정하고   
scoring time(판독시간)을 비교하며   
computer-assisted semi-automatic scoring(자동 판독 후 전문가 검토)에서 효율성과 합의도를 개선하는지 평가하기 위한 데이터셋

   
task별 5개의 PSG를 두고, 12명의 숙련된 sleep technician이 각각 동일한 기록을 다시 판독

---
## 🗂️ 데이터 특징

- multi-rater annotation이 핵심
- task가 sleep stage에만 한정되지 않음
- arousal, leg movement, respiratory event까지 포함
- manual vs semi-automatic 판독 비교 가능
- event onset/offset editing 관점 연구 가능
